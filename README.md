# Wrong Way Vehicle Detection

A computer vision project that detects vehicles moving in the wrong direction using YOLOv8 and OpenCV.

## Features

- Vehicle detection using YOLOv8
- Vehicle tracking
- Wrong-way vehicle detection
- Video processing

## Technologies Used

- Python
- OpenCV
- YOLOv8
- NumPy

## How to Run

1. Install dependencies

```bash
pip install -r requirements.txt
```

2. Run

```bash
python wrongway.py
```
